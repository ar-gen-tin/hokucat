# Changelog

These entries describe verified changes in the preview builds. See the [project overview](README.md) for demos and the current preview status. An installer is not publicly available while distribution review is pending.

## 1.4.74 — Preview build

Installer pending distribution review.

- Star Citizen uses a still cover while browsing the review library, avoiding unnecessary simultaneous video playback. Selecting a cover does not need to start another video player.

## 1.4.73 — Review build

- Reworked the Hokucat cat scene, retaining pointer tracking, the draggable star, and its star trail.
