# Contributing to Hokucat

## Share a wallpaper / 分享壁纸

Made a wallpaper with AI or your own media? [Share your wallpaper](https://github.com/ar-gen-tin/hokucat/issues/new?template=share_wallpaper.yml) with a preview, your name, and a short description of how you made it. Include the asset sources and whether you have tried it in Hokucat. AI prompts, scripts, and package links are optional. You do not need a pull request or an installed Hokucat build to share a preview.

用 AI 或自己的素材做了壁纸？[分享你的作品](https://github.com/ar-gen-tin/hokucat/issues/new?template=share_wallpaper.yml)，附上预览、作者署名和简单的制作方法，说明素材来源以及是否在 Hokucat 中试过。AI 提示词、脚本和作品包链接均可选填。不需要提交 PR，也不用先安装应用，就能分享预览。

Thanks for helping make Hokucat clearer and easier to use. This public repository contains documentation, showcase materials, and a wallpaper creation example. The complete Mac application source is not included here.

## Report an app problem

Search the [issues](https://github.com/ar-gen-tin/hokucat/issues) first, then open one with:

- Your Hokucat version and macOS version.
- The wallpaper title and original page, if applicable.
- Steps to reproduce, the expected result, and what happened.
- Display count and resolutions for display-related problems.
- A screenshot or short recording when useful, with private content removed.

Describe a feature request through the result you want on your desktop and why it helps. A small example is useful.

## Improve the public files

Documentation fixes, translations, and improvements to `examples/make-wallpaper.py` are welcome as pull requests. Keep each change focused and explain what it improves and how you checked it.

- **Documentation:** verify relative links and keep release availability and supported formats accurate.
- **Translations:** use the English README as the reference, preserve all nine language links, and keep product and interface names recognizable. Flag any text that needs a native speaker’s review.
- **Examples:** explain dependencies and how to run the example. For media changes, check the output format, whether the package imports, and the loop boundary. State clearly if you could not test it in Hokucat.

Do not claim compatibility based only on a screenshot, a recording, or a successful conversion. A wallpaper must be tested in the actual app for the behavior being described.

## Respect the creators

Use original material or material you have permission to contribute. Include the author, original page, and the relevant usage conditions for each asset. Do not upload third-party Workshop packages or their media as contribution attachments without permission to redistribute them.

Third-party PC works in the current preview are **for testing only**. Their credits do not turn them into Hokucat originals or grant reuse rights. See [Credits](docs/credits.md). The procedural animation generated by the public example is documented separately.

素材需为原创或已获准贡献的内容，并附作者、原页和适用条件。第三方 PC 测试作品必须保留「仅供测试使用」说明，不得作为 Hokucat 原创或未经许可的再分发内容提交。详情见[署名页](docs/credits.md)。
