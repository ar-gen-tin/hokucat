## تجربة Hokucat

**الإصدار <span dir="ltr">1.4.80</span> هو نسخة معاينة موقّعة بشهادة <span dir="ltr">Developer ID</span>**، وتدعم **<span dir="ltr">macOS 13</span> أو أحدث** على أجهزة Mac بمعالجات **<span dir="ltr">Apple Silicon</span> أو <span dir="ltr">Intel</span>**. لم تخضع نسخة المعاينة هذه للتوثيق لدى Apple؛ وقد يمنع <span dir="ltr">macOS</span> فتح التطبيق للمرة الأولى. راجع [سجل التغييرات](../../CHANGELOG.md) للاطلاع على التحديثات.

نزّل ملف <span dir="ltr">DMG</span> وافتحه، واسحب <span dir="ltr">Hokucat</span> إلى مجلد <span dir="ltr">Applications</span> (التطبيقات)، ثم اتبع الخطوات التالية:

1. شغّل <span dir="ltr">Hokucat</span> من مجلد <span dir="ltr">Applications</span> (التطبيقات)، ثم اختر **لوحة التحكم بالخلفيات…** من شريط القوائم.
2. اختر خلفية. يمكنك معاينتها وضبط عناصر التحكم المتاحة لذلك العمل في الصفحة نفسها.
3. اضغط **تطبيق الخلفية**. إذا كنت تستخدم أكثر من شاشة، فاختر الشاشة المطلوبة أولًا.

## اجعل سطح المكتب مناسبًا لك

- **مكتبة سهلة التصفح.** ابحث عن خلفية، ورتّب مجموعتك يدويًا أو حسب الاسم.
- **المعاينة والإعدادات في مكان واحد.** شاهد العمل المحدد بجانب عناصر التحكم الخاصة به. في مقاطع الفيديو المدعومة، يمكنك ضبط ملاءمة الصورة للشاشة والسرعة والقلب الأفقي قبل التطبيق.
- **إدارة بسيطة للمكتبة.** اسحب العناصر لإعادة ترتيبها، واستخدم قائمة الزر الأيمن للإجراءات المعتادة، وأزل الخلفيات المستوردة بعد التأكيد. تبقى ملفاتك الأصلية في أماكنها.
- **تفاعل مألوف على Mac.** استخدم Hokucat من شريط القوائم، وواصل التعامل مع سطح المكتب بالطريقة المعتادة، وتفاعل مع تتبّع القطة للمؤشر والنجمة القابلة للسحب. تختلف التفاعلات المتاحة من خلفية إلى أخرى.
- **اختيار مستقل لكل شاشة.** استخدم خلفية مختلفة على كل شاشة متصلة؛ يتذكر Hokucat اختياراتك.

واجهة التطبيق متاحة **بالإنجليزية والصينية المبسطة والصينية التقليدية واليابانية والكورية والبرتغالية البرازيلية والإسبانية والفرنسية والعربية**. اختر اللغة من الإعدادات.

## إنشاء خلفية بالذكاء الاصطناعي

استخدم Codex أو Claude Code أو Grok Bot لإنشاء فيديو أصلي صامت يتكرر، أو استخدم فيديو لديك إذن باستخدامه. يتضمن [دليل الإنشاء](../ai-wallpapers.md) نصًا توجيهيًا ومثالًا قابلًا للتشغيل ينشئ حزمة جاهزة للاستيراد من **لوحة التحكم بالخلفيات** عبر **استيراد…**.

يدعم <span dir="ltr">Package v1</span> **صور <span dir="ltr">PNG/JPEG</span> ومقاطع فيديو صامتة بصيغ <span dir="ltr">MP4/MOV/M4V</span>**. يساعد الذكاء الاصطناعي في إنشاء الوسائط، بينما يشغّل Hokucat الملفات المستوردة محليًا. لا تشمل صيغة الحزمة هذه مشاريع Web أو Windows Scene التفاعلية العامة، أو إدخال حركة المؤشر أو الصوت في الوقت الفعلي، أو الاتصالات المباشرة بواجهات API أو الوكلاء. قد تتضمن بعض الخلفيات المدمجة أو المعدّلة ميزات تفاعلية خاصة بها.

الرسوم المتحركة التي ينشئها <a href="../../examples/make-wallpaper.py" dir="ltr"><code dir="ltr">examples/make-wallpaper.py</code></a> برمجيًا هي مثال مستقل أُعدّ لهذا المستودع. وهي منفصلة عن خلفيات الكمبيوتر الشخصي التابعة لمبدعين آخرين والمعروضة لأغراض الاختبار.
