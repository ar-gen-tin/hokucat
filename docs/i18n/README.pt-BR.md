## Experimente o Hokucat

**A versão de prévia atual é a 1.4.74. O instalador ainda não está disponível para download público.** Os materiais de prévia estão nesta página; veja as atualizações no [histórico de alterações](../../CHANGELOG.md).

A versão atual para Mac é destinada ao **macOS 13 ou posterior**, em **Apple Silicon e Intel**. Se você já tem uma versão para avaliação:

1. Abra o Hokucat pela barra de menus e escolha **Painel de papéis de parede…**.
2. Selecione um papel de parede. Veja a prévia e ajuste os controles disponíveis para aquela obra na mesma página.
3. Clique em **Aplicar papel de parede**. Se você usa mais de uma tela, escolha primeiro a tela de destino.

## Deixe a área de trabalho do seu jeito

- **Uma biblioteca para explorar.** Encontre um papel de parede pela busca, organize a coleção manualmente ou ordene por nome.
- **Prévia e ajustes juntos.** Veja a obra selecionada ao lado dos controles. Nos vídeos compatíveis, ajuste o encaixe na tela, a velocidade e o espelhamento horizontal antes de aplicar.
- **Gerenciamento simples da biblioteca.** Arraste os itens para mudar a ordem, use o menu do botão direito para ações comuns e remova papéis de parede importados após confirmar. Os arquivos de origem permanecem onde estão.
- **Interações familiares no Mac.** Acesse o Hokucat pela barra de menus, continue usando os controles habituais da área de trabalho e brinque com o olhar do gato e a estrela que pode ser arrastada. As interações disponíveis variam conforme o papel de parede.
- **Escolhas por tela.** Use um papel de parede diferente em cada tela conectada. O Hokucat lembra suas escolhas.

A interface do aplicativo está disponível em **inglês, chinês simplificado, chinês tradicional, japonês, coreano, português brasileiro, espanhol, francês e árabe**. Escolha o idioma nos ajustes.

## Crie um papel de parede com IA

Use o Codex, o Claude Code ou o Grok Bot para criar um vídeo original em loop e sem som, ou use um vídeo que você tenha permissão para utilizar. O [guia de criação](../ai-wallpapers.md) inclui um prompt e um exemplo executável que gera um pacote pronto para **Painel de papéis de parede → Importar…**.

O Package v1 aceita **imagens PNG/JPEG e vídeos MP4/MOV/M4V sem som**. A IA ajuda a criar a mídia; o Hokucat reproduz os arquivos importados localmente. Projetos interativos genéricos de Web ou Windows Scene, entrada de cursor ou áudio em tempo real e conexões em tempo real com APIs ou agentes não fazem parte desse formato de pacote. Alguns papéis de parede integrados ou adaptados podem ter seus próprios recursos interativos.

A animação gerada por código em [`examples/make-wallpaper.py`](../../examples/make-wallpaper.py) é um exemplo independente criado para este repositório. Ela é separada dos papéis de parede de terceiros para PC apresentados para testes.
