## 試用 Hokucat

**1.4.77 是以 Developer ID 簽署的預覽版**，支援 **macOS 13 或更新版本**的 **Apple 晶片與 Intel** Mac。此預覽版未經 Apple 公證，macOS 可能阻擋首次開啟。版本變更請見[更新紀錄](../../CHANGELOG.md)。

下載並開啟 DMG，將 Hokucat 拖入 Applications（應用程式）資料夾後：

1. 從 Applications（應用程式）資料夾啟動 Hokucat，再從選單列選擇**桌布面板…**。
2. 選取桌布，在同一頁預覽並調整該作品提供的控制項。
3. 按下**套用桌布**。使用多部顯示器時，先選擇要套用的螢幕。

## 依照自己的習慣設定桌面

- **瀏覽桌布收藏。** 用搜尋尋找桌布，手動排列收藏或按名稱排序。
- **預覽與設定放在一起。** 選取的作品和控制項顯示在同一頁。支援的影片可在套用前調整畫面適配方式、速度與水平翻轉。
- **管理收藏。** 拖曳調整順序，按右鍵使用常用操作，經確認後移除已匯入的桌布。原始檔案仍留在原來的位置。
- **熟悉的 Mac 操作。** 從選單列使用 Hokucat，保留熟悉的桌面操作，也能和小貓的追視與可拖曳星星互動。各桌布提供的互動功能不同。
- **每部顯示器分別設定。** 可為每部已連接的顯示器選擇不同桌布，Hokucat 會記住選擇。

應用程式介面提供**英文、簡體中文、繁體中文、日文、韓文、巴西葡萄牙文、西班牙文、法文與阿拉伯文**，可在設定中切換。

## 用 AI 創作桌布

用 Codex、Claude Code 或 Grok Bot 製作原創的靜音循環影片，或使用你有權使用的影片。[創作指南](../ai-wallpapers.md) 提供提示詞與可執行範例，可產生能透過**桌布面板 → 匯入…**載入的作品包。

Package v1 支援 **PNG/JPEG 圖片與靜音 MP4/MOV/M4V 影片**。AI 協助製作素材，Hokucat 在本機播放匯入的檔案。這個作品包格式不支援通用互動式 Web 或 Windows Scene 專案、即時游標或音訊輸入，也不支援即時 API 或 Agent 連線。部分內建或改編桌布可有各自的互動功能。

[`examples/make-wallpaper.py`](../../examples/make-wallpaper.py) 產生的程式動畫是為本倉庫製作的獨立範例，與僅供測試展示的第三方 PC 桌布分開。

## 問題、回饋與署名

相容性與匯入方式請見[常見問題](../faq.md)。也可[回報問題](https://github.com/ar-gen-tin/hokucat/issues)，附上 macOS 版本、Hokucat 版本和重現步驟。歡迎改善文件、翻譯與範例，請見[貢獻指南](../../CONTRIBUTING.md)。

本倉庫包含公開文件、展示素材與創作範例，**不包含完整的 Mac 應用程式原始碼**。已記錄的預覽版變更請見[更新紀錄](../../CHANGELOG.md)。

Hokucat 從 **0xCodila (Bodila51)** 的 [Grok Bot Wallpaper](https://github.com/Bodila51/grokbot-wallpaper) 發展而來。第三方作品保留原作者署名，在測試版中展示不代表取得再分發許可。[專案沿革與素材署名](../credits.md)
