## Hokucat 사용해 보기

**1.4.91은 Developer ID로 서명된 미리보기 버전**이며, **macOS 13 이상**의 **Apple Silicon 및 Intel** Mac을 지원합니다. 이 미리보기 버전은 Apple 공증을 받지 않아 macOS가 처음 실행을 차단할 수 있습니다. 변경 사항은 [변경 기록](../../CHANGELOG.md)을 확인하세요. Apple Silicon 및 Intel용으로 빌드되었지만, 이 버전의 Intel 실기기 실행은 검증하지 않았습니다.

DMG를 다운로드해 열고 Hokucat을 Applications(응용 프로그램) 폴더로 드래그한 뒤:

1. Applications(응용 프로그램) 폴더에서 Hokucat을 실행한 다음 메뉴 막대에서 **배경화면 대시보드…**를 선택하세요.
2. 배경화면을 선택하세요. 같은 화면에서 미리 보고 해당 작품에서 제공하는 설정을 조절할 수 있습니다.
3. **배경화면 적용**을 클릭하세요. 디스플레이가 여러 개라면 적용할 디스플레이를 먼저 선택하세요.

## 내게 맞는 데스크톱 만들기

- **둘러보기 쉬운 라이브러리.** 검색으로 배경화면을 찾고, 직접 순서를 바꾸거나 이름순으로 정렬할 수 있습니다.
- **미리보기와 설정을 한곳에서.** 선택한 작품과 설정을 함께 확인하세요. 지원되는 동영상은 적용 전에 화면 맞춤 방식, 속도, 좌우 반전을 조절할 수 있습니다.
- **간단한 라이브러리 관리.** 항목을 드래그해 순서를 바꾸고, 오른쪽 클릭 메뉴에서 자주 쓰는 작업을 실행하며, 확인 후 가져온 배경화면을 제거할 수 있습니다. 원본 파일은 원래 위치에 그대로 남습니다.
- **익숙한 Mac 조작.** 메뉴 막대에서 Hokucat을 사용하면서 평소처럼 데스크톱을 조작하고, 고양이의 시선 추적과 드래그 가능한 별을 즐겨보세요. 제공되는 상호작용은 배경화면마다 다릅니다.
- **디스플레이별 설정.** 연결된 디스플레이마다 다른 배경화면을 선택할 수 있습니다. Hokucat은 선택한 내용을 기억합니다.

앱 인터페이스는 **영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 브라질 포르투갈어, 스페인어, 프랑스어, 아랍어**로 제공됩니다. 설정에서 언어를 선택하세요.

## AI로 배경화면 만들기

Codex, Claude Code 또는 Grok Bot으로 나만의 무음 반복 동영상을 제작하거나, 사용 권한이 있는 동영상을 준비하세요. [제작 가이드](../ai-wallpapers.md)에는 **배경화면 대시보드 → 가져오기…**로 불러올 수 있는 패키지를 만드는 프롬프트와 실행 가능한 예제가 있습니다.

Package v1은 **PNG/JPEG 이미지와 무음 MP4/MOV/M4V 동영상**을 지원합니다. AI는 미디어 제작을 돕고, Hokucat은 가져온 파일을 로컬에서 재생합니다. 일반적인 인터랙티브 Web 또는 Windows Scene 프로젝트, 실시간 포인터나 오디오 입력, 실시간 API 또는 에이전트 연결은 이 패키지 형식의 지원 범위에 포함되지 않습니다. 일부 내장 또는 이식된 배경화면에는 자체 상호작용 기능이 있을 수 있습니다.

[`examples/make-wallpaper.py`](../../examples/make-wallpaper.py)가 생성하는 애니메이션은 이 저장소를 위해 만든 독립적인 예제입니다. 테스트 목적으로 소개하는 타 제작자의 PC용 배경화면과는 별개입니다.

이 저장소에는 공개 문서, 소개 자료, 제작 예제가 들어 있습니다. **Mac 앱 전체 소스 코드는 포함되어 있지 않습니다.** 기록된 프리뷰 변경 사항은 [변경 이력](../../CHANGELOG.md)에서 확인하세요.
